# Neon Digital Clock & Alarm

A futuristic neon-style digital clock web app with a countdown timer, alarm clock, sound controls, and customizable colour themes.

## Features

- Live digital clock with AM/PM and date
- Countdown timer with start, pause, and reset controls
- Alarm that can use a built-in digital tone or a user-selected audio file
- Test and stop alarm sound controls
- Preset neon themes: blue, green, red, purple, pink, orange, and cyan
- Custom colour picker
- Responsive layout for desktop and mobile browsers

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Allow audio playback when prompted or click **TEST SOUND** to enable sound.

No build tools or package installation are required.

## Host with GitHub Pages

1. Create a GitHub repository named `neon-digital-clock`.
2. Upload `index.html` and `README.md` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for deployment. GitHub will show your website URL in the Pages section.

## Important notes

- Keep the webpage open for alarms to work. Browser or device sleep settings may delay or prevent alarms.
- Browsers may require a user click before audio can play.
- Custom audio files are played locally in your browser and are not uploaded by this webpage.
- This project uses Google Fonts, so the Orbitron font requires an internet connection; a fallback monospace font is included.
